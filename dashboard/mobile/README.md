# JBS Mobile Development Dashboard

Mobile-first dashboard for viewing real JBS development status.

## Current evidence
- JBS Agri Hub: existing source / development branch / CI foundation.
- Other 11 apps: newly generated source foundation; production implementation is not marked complete.

## Install
Open the hosted dashboard in a mobile browser and choose **Add to Home Screen**. The manifest is configured for standalone display where supported.

## Truth rule
UI must never invent progress. Replace status values only from repository evidence (commits, CI runs, tests, builds, releases).
